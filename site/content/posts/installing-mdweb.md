---
title: "Installing mdweb"
date: "2026-08-04"
tags: ["tutorial", "setup"]
---

mdweb is a single static binary. Grab a release from GitHub or build
from source with `cargo install mdweb`. Once on your `$PATH`, run:

```bash
mdweb create my-blog
cd my-blog
mdweb run
```

Then open <http://127.0.0.1:8080> and you'll see the demo site.
